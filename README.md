# qcameraapp6 — その場で学習するカメラ物体検出アプリ

スマホのブラウザだけで「対象を枠で囲んで撮影 → その場で学習 → リアルタイム検出」ができるWebアプリです。
学習も推論もブラウザ内（TensorFlow.js）で行います。

- 検出方式：MobileNet v1 の特徴 ＋ 14×14 マスの判定（YOLO ではありません）
- 見分けられる対象は1種類

詳しい仕様は [SPEC.md](./SPEC.md) を見てください。

## 使い方
1. ページを開き、カメラの使用を許可します。状態表示が「準備OK」になるまで待ちます。
2. `学習` を押し、画面をドラッグして対象を囲みます。`撮影` で保存します。角度や距離を変えて何枚か撮ります。
3. 対象が写っていない場面も `背景` で何枚か撮ると、誤検出が減ります。
4. `学習開始` を押します。終わったら `検出する` を押すと、映像の中の対象に枠が出ます。
5. 学習結果は 💾 でファイルに保存し、📂 で読み込めます。

## 動かし方
カメラを使うため、HTTPS か `localhost` で開く必要があります。ローカルで試す例：

```sh
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

起動時に TensorFlow.js（jsDelivr）と MobileNet の重み（Google のストレージ）をネットから読み込むため、インターネット接続が必要です。
